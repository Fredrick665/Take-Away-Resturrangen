# Take-Away-Resturrangen
Examensarbete För Furious Scientists



# Välkommen till vårt kreativa kök!

Detta projekt är en komplett lösning för en take away-restaurang '**SwiftDeluxe Restaurant**' som fokuserar på att skapa en smidig och engagerande upplevelse för både kunder och personal.


## Funktioner
- **Kunder**:
  - Läsa menyn
  - Göra och hantera beställningar
  - Få information om restaurangen
  - Lägga till kommentarer eller ändra ingredienser i beställningen
- **Personal**:
  - Hantera beställningar (se, ändra, låsa)
  - Lägga kommentarer för kockarna

## Teknologi
- **Frontend**: React
- **Backend**: AWS Serverless
- **Design**: Prototyper i Figma
- **Databas**: DynamoDB
